基于 Python Tkinter 开发的太空狼人杀桌游，支持单机同屏（4-10 人）与局域网联机（4-10 人）对战。

## 游戏简介

**太空狼人杀**是一款回合制策略推理游戏，灵感来源于经典游戏 Among Us。玩家将被分配为**船员**或**内鬼**两种角色，在太空飞船中展开紧张刺激的生存与欺骗之战。

三名中国中学生所作。我们时间十分有限，请静待后续更新。

## 游戏规则

### 角色分配

| 玩家数量 | 内鬼数量 |
|:--------:|:--------:|
| 4-6人    | 1人      |
| 7-10人   | 2人      |

### 胜利条件

**船员胜利：**
- 完成所有常规任务（每名船员需完成3个任务）
- 投票出局所有内鬼

**内鬼胜利：**
- 内鬼数量与船员数量相等（且已有人出局）
- 氧气系统被破坏后船员未在限定时间内修复

## 游戏界面

### 模式选择大厅（v2.0.0 新增）
- **单机模式**：原同屏轮流操作玩法
- **创建房间**：显示本机局域网 IP，等待其他玩家加入
- **加入房间**：输入房主 IP 与自己的名称即可连接

### 角色查看
- 显示玩家名称和角色（船员/内鬼）
- 角色专属提示信息
- 任务数量提示（仅船员）

### 游戏主界面
- **顶部状态栏**：全局回合数、行动步数、紧急会议次数、冷却状态
- **左侧地图**：飞船地图，可点击移动
- **右侧信息面板**：当前玩家信息、任务进度
- **底部日志**：游戏事件记录

## 核心功能

### 移动系统
- 每回合拥有4点行动步数
- 点击地图上的房间进行移动
- 相邻房间才能移动

### 任务系统（船员）
船员需要完成3个常规任务：

| 任务名称 | 位置 | 难度 |
|:--------:|:----:|:----:|
| 修复电线 | 电力室 | ★ |
| 清理过滤器 | 氧气室 | ★ |
| 扫描身体 | 医疗室 | ★★ |
| 下载数据 | 通讯室 | ★★ |
| 校准引擎 | 引擎室 | ★★ |
| 反应堆维修 | 反应堆 | ★★★ |
| 燃料补给 | 燃料室 | ★★ |
| 启动卫星 | 监控室 | ★★★ |
| 摩斯密码 | 主控室 | ★★★ |

### 炸弹系统（内鬼）- v1.1.0新增

**放置炸弹：**
- 内鬼可在任意房间放置炸弹
- 消耗1点行动步数
- 放置冷却：5回合（联机模式改为 150 秒）
- 炸弹倒计时：3分钟（单机，独立实时计时）；联机模式为 60 秒

**炸弹爆炸效果：**
- 炸死炸弹所在房间内所有船员（内鬼不受影响）
- 在氧气室爆炸 → 触发氧气系统修复任务
- 在监控室爆炸 → 触发监控系统修复任务
- 在飞船大厅爆炸 → 禁用紧急会议功能2回合

**拆弹任务：**
- 船员在有炸弹的房间可进行拆弹
- 按正确顺序剪断4条电线
- 30秒倒计时，剪错或超时炸弹爆炸

### 废墟清理系统 - v1.2.0新增

**废墟生成：**
- 炸弹爆炸后，所在房间变成废墟状态
- 废墟房间无法执行常规任务
- 地图上显示🏚️标记

**清理废墟：**
- 船员需在有废墟的房间点击"清理废墟"按钮
- 拖拽碎片到垃圾桶完成清理
- 清理完成后恢复房间正常功能
- 飞船大厅为废墟时无法发起紧急会议

## 联机功能 - v2.0.0新增

### 连接协议
- 基于 TCP 的房间大厅系统
- 房主显示本机局域网 IP，其他玩家输入 IP 加入
- 自动同步玩家信息和游戏状态

### 游戏同步
- 实时同步所有玩家的任务完成状态
- 投票结果与出局同步
- 炸弹放置与爆炸同步
- 所有玩家移动轨迹同步

## 安装与运行

### 环境要求
- Python 3.11 或更高版本
- Tkinter（通常随 Python 一起安装）

### 运行游戏

**单机模式：**
```bash
python main_gui.py
```

**联机模式：**
```bash
# 房主（创建房间）
python impostor_entry.py  # 或 crewmate_entry.py

# 玩家（加入房间）
python impostor_entry.py  # 或 crewmate_entry.py
```
