# 太空狼人杀 更新日志

## v1.1.0 - 炸弹系统更新

### 新增功能

#### 💣 炸弹系统
- **放置炸弹**：内鬼可在任意房间放置炸弹
  - 消耗1点行动步数
  - 放置冷却：5回合
  - 炸弹倒计时：3分钟（独立实时计时）
  - 所有玩家可见炸弹倒计时显示

- **炸弹爆炸效果**：
  - 炸死炸弹所在房间内所有船员（内鬼不受影响）
  - 在氧气室爆炸 → 触发氧气系统修复任务（2回合倒计时）
  - 在监控室爆炸 → 触发监控系统修复任务

- **监控室炸弹标注**：
  - 有炸弹的房间用红色粗边框标注
  - 房间名称前显示 💣 标记
  - 背景变为深红色醒目提示

#### 🔧 拆弹任务
- **任务入口**：船员在有炸弹的房间时，显示红色"💣 拆弹任务"按钮
- **任务玩法**（参考《三角洲行动》水淹大坝）：
  - 显示4种颜色的剪线顺序（如：红→蓝→绿→黄）
  - 30秒倒计时
  - 按正确顺序点击对应颜色按钮剪断电线
  - 剪对显示进度，剪错或超时炸弹爆炸
- **视觉效果**：
  - 深色科技风格界面
  - 电线纵向排列（1,1,1,1布局）
  - 剪断电线后显示断开效果（灰色虚线 + 红色X标记）

### 功能优化

#### 监控室改进
- 报告尸体后自动对所有存活玩家设置2回合监控冷却
- 关闭监控窗口也会触发2回合冷却
- 新增炸弹位置红色标注显示

#### 任务界面美化
- **校准下降引擎**：
  - 深色科技风格背景
  - 真实的引擎圆环设计（发光效果、金属质感）
  - 滑动条优化

- **校准上升引擎**：
  - 真实的方形接口设计（燃料出口/接口）
  - 管道科技蓝配色
  - 正方形阀门按钮
  - 接口随机生成在界面左2/3区域，100像素内不重复

### Bug修复
- 修复炸弹爆炸时弹出多个窗口的问题
- 修复拆弹成功后炸弹不消失的问题
- 修复 `Impostor` 类缺少 `bomb_explode_time` 属性的问题

### 技术改进
- 炸弹倒计时使用 `time.time()` 独立计时，不再依赖回合切换
- 拆弹任务使用回调机制，确保任务结果正确传递
- 添加 `bomb_location` 变量跟踪炸弹位置
